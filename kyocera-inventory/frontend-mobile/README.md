# Frontend Mobile (Day4)

React 18 + TypeScript + Viteで作る、Smartphone向け在庫入出庫の学習画面です。

- URL: `http://localhost:5175/stock-operation`
- `ITEM001`等の商品CodeをBarcode / QRから読み取った値とみなします。
- これは学習用仮定であり、実案件のBarcode仕様・画面仕様ではありません。
- 入庫はBackendまで完成しています。出庫のBackend業務処理はExerciseとして残しています。

```bash
npm ci
npm test
npm run build
npm run dev
```
